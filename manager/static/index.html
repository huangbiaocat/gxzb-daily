重点跟踪核心规则

独立规则·命中即重点

独立强规则：只要标讯标题命中指定项目名称，即无条件判定为重点标讯（不受金额门槛限制）。已支持智能模糊匹配与分词匹配。

独立规则·命中即重点

独立强规则：当招标人或标讯标题包含指定业主单位全称或简称时，直接判定为重点标讯（不受金额门槛限制）。

云端服务器同步 (SCP / SSH)

开启后，每日自动化调度运行结束将直接通过 SSH 上传至云服务器。
当前电脑默认检测路径:
【换电脑安装/迁移后，私钥应该放哪里？】
方案 A（Windows 万能快捷方式，最省心）：按下键盘 Win + R 打开运行窗口，输入 %USERPROFILE%\.ssh 并回车。系统会自动打开当前用户的 SSH 文件夹，将私钥文件重命名为 id_rsa 粘贴进去即可。
方案 B（随软件便携模式）：直接把私钥文件复制到本软件的 data/ 目录下（命名为 id_rsa 或 vps_key.pem），软件会自动优先使用。
方案 C（自定义任意位置）：放在电脑任意盘符，在上方【指定私钥文件路径】输入完整绝对路径。
